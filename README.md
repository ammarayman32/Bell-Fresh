# Bell Fresh – Food Ordering App

A responsive food ordering application built with React, allowing users to explore meals, search for dishes, filter by categories, and manage their shopping cart.

## Features

- **Search Meals:** Dynamically search for meals by name.
- **Category Filtering:** Filter meals by their categories.
- **Shopping Cart:** Add meals to the cart and manage item quantities.
- **Price Calculation:** Automatically calculate the cart subtotal and apply a 10% discount.
- **Cart Management:** Clear the cart and manage its visibility.
- **Responsive Design:** Optimized layout for different screen sizes.

- React.js

- HTML5

- React Hooks (`useState`)
- Lucide React

## Getting Started

Clone the repository:

```bash
git clone https://github.com/ammarayman32/Bell-Fresh.git
```

Navigate to the project directory:

```bash
cd Bell-Fresh
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm start
```

The application will run at `http://localhost:3000`.
